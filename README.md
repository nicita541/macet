# Erudition Browser UI Lab

Редактируемый браузерный макет игры **Erudition**.

## Как он теперь устроен

Текущая версия **не режет пользовательские скриншоты на картинки** и не хранит `data:image/base64`-фрагменты.

Источник визуальных элементов:
- `nicita541/game123/Assets/Art/ui_library_background.png` — фон;
- `Assets/Art/SpriteSheets/*.png` — кнопки, панели, иконки, декор, авторы;
- `Assets/Art/owl_*.png` — состояния совы;
- `Assets/Art/Fonts/*.ttf` — шрифты.

Скриншоты, присланные пользователем в чате, используются **только как эталон компоновки**: координаты, размеры, отступы и внешний вид экранов.

## Экраны

- Главная
- Настройки
- Статистика
- Достижения
- Магазин
- Игровой экран
- Уровни / Авторы

Каждый крупный объект имеет стабильный `data-ui` ID. В режиме **«Объекты»** можно нажать на элемент и получить его ID, например `home/owl`, `shop/pack-15`, `collections/author-3`.

Это позволяет отдельно двигать, масштабировать, заменять и анимировать элементы без перерисовки всего экрана.
