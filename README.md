# Erudition Browser UI Lab

Редактируемый браузерный макет интерфейса игры **Erudition**.

## Источник дизайна

**Единственный визуальный эталон — скриншоты, присланные пользователем в чате 2026-09-30.**

Старые готовые референсы из `game123` (`Review/...`, `Assets/ReferenceOnly/...`, numbered PNG и т.п.) **не являются эталоном и не должны использоваться для компоновки**.

Из `game123` можно брать только отдельные исходные игровые ассеты: сову, иконки, спрайт-листы и чистый фон. Их положение, размеры и композиция определяются по пользовательским скриншотам.

## Правило визуальной проверки

Перед каждым визуальным коммитом:
1. Сравнить экран с соответствующим пользовательским скриншотом.
2. Проверить координаты, размеры и отступы крупных блоков.
3. Проверить отсутствие старого UI, запечённого в фоне.
4. Проверить, что нет дублей совы, заголовков, ресурсов, карточек и навигации.
5. Проверить мобильный вид без служебных подсказок поверх экрана.

Все редактируемые элементы имеют `data-ui` ID и должны оставаться отдельными объектами.
