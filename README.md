# Erudition Browser UI Lab

Браузерный макет интерфейса игры Erudition для совместной работы над дизайном.

## Источники

- Эталон расположения и композиции: только скриншоты, присланные в чат.
- Графика: реальные ассеты nicita541/game123/Assets/Art — совы, иконки, sprite sheets и фоновые арты.
- Старые полноэкранные референсы из Review/FeedbackPass и Assets/ReferenceOnly не используются.
- В репозитории нет нарезанных скриншотов и нет data:image/base64.

Карточки, тексты, переключатели, кнопки и контейнеры являются отдельными HTML/CSS-объектами. Sprite sheets режутся в браузере по координатам из Unity .meta.

## Режим «Объекты»

Включи «Объекты» и нажми на элемент. У него будет стабильный ID, например home/owl, shop/feathers/pack-15, settings/music/toggle или collections/author-3/portrait.

Базовый холст: 475×957.
