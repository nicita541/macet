# Erudition Browser UI Lab

Редактируемый браузерный макет интерфейса игры **Erudition**.

Это **не игра** и не перенос Unity-логики. Макет нужен для совместной работы над визуалом:
- все ключевые элементы — отдельные HTML/CSS-объекты;
- можно менять размеры, позиции, композицию и анимации;
- можно переключаться между экранами;
- есть режим дизайнера: клик по объекту показывает его `data-ui` ID;
- есть прозрачное наложение текущего Unity-референса для сравнения.

## Экраны
Главная, Уровни, Библиотека (Авторы/Темы/Книги/Типы), Статистика, Достижения, Магазин, Настройки, Игровой экран и попапы.

## Быстрый просмотр
Открыть `index.html` локально или использовать raw.githack для ветки `main`.

Исходные игровые изображения пока берутся напрямую из репозитория:
`nicita541/game123`.

Так макет сразу использует актуальную сову/фон/референсы, а затем нужные утверждённые ассеты можно перенести сюда отдельно.
