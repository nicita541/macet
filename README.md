# Erudition UI Lab

Браузерный макет интерфейса игры **Erudition**.

## Эталон
Единственный источник внешнего вида — **7 скриншотов, присланных пользователем в чате**:
Главная, Настройки, Статистика, Достижения, Магазин, Игра, Уровни.

Старые reference/Review PNG из `game123` не используются как эталон дизайна.

## Как собран макет
Каждый экран 475×957 разбит на отдельные независимые визуальные участки (tiles) с `data-ui` ID.
Вместе они восстанавливают исходный скриншот без смещения. В режиме **«Объекты»** можно выбрать участок и затем заменить именно его, не переделывая весь экран.

## Проверка
Перед загрузкой текущей версии все 7 экранов были программно собраны обратно из сохранённых tiles и сравнены с исходными присланными скриншотами:
- max pixel diff: 0
- changed pixels: 0

Это проверка исходной композиции до браузерного масштабирования.

## Работа
1. Открыть `index.html`.
2. Выбрать экран.
3. Включить **«Объекты»**.
4. Нажать нужный участок.
5. Сообщить его ID и требуемое изменение.
