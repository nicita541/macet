# Erudition Pixel UI Lab

Браузерный макет для подбора дизайна игры **Erudition**.

## Важно
Макет теперь строится по текущим Unity-скриншотам **без придумывания нового дизайна**.

Каждый экран имеет:
- отдельный фон из `game123/Assets/Art/Backgrounds`;
- отдельные редактируемые визуальные блоки (шапка, сова/hero, карточки, кнопки, нижняя навигация и т.д.);
- каждый блок имеет стабильный `data-ui` ID;
- точный Unity-скриншот используется только как источник пикселей для конкретных блоков и как слой сравнения — не как одна полноэкранная картинка интерфейса.

Так мы сохраняем вид текущей игры и можем по одному заменять/двигать объекты.

## Как работать
1. Открой `index.html`.
2. Выбери экран.
3. Включи **Объекты**.
4. Нажми нужный блок.
5. Сообщи его ID, например: `home/hero`, `shop/feathers-panel`, `collections/author-3`.
6. Правка делается только для этого объекта.

**Сравнить** накладывает исходный Unity-скриншот поверх макета с регулируемой прозрачностью.

Исходный проект: `nicita541/game123`.
